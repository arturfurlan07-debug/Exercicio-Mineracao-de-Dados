# Projeto de Mineração de Dados - IBGE

Este projeto realiza o agrupamento de estados brasileiros (K-Means) e a extração de regras de associação (Apriori) a partir de dados da produção industrial do IBGE.

## 🛠️ Requisitos e Instalação

1. Certifique-se de ter o Python 3 instalado.
2. Instale as dependências necessárias executando o comando no terminal:

```bash
